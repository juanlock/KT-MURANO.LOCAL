#731 Completed Production working again after the user re-uploaded the production DB and code. Answered: the dev <-> production DB sync is Pa Llevar step 1c (protocol_prod_migrate.php dev -> prod migrations
Requested Sun, Oct 18, 2026 · 12:38 AM · at Optimum · Category: question · Company: All companies
Request
ok ya termine de subir la base de datos de produccion y el codigo.. y ahora funciona.. consulta.. cual es el protocolo que permite actualizar la base de datos de prod con los nuevos cambios de la bd de developer y actualziar la bd de developer con la inforamcion de produccion ?
Understood as
Which protocol syncs dev database changes to production and production data to dev.
Solution

Es el paso 1c de Pa Llevar (antes de Copia BD): dev -> producción = protocol_prod_migrate.php (migraciones pendientes, confirmación, respaldo de producción, migrate; nunca filas de dev); producción -> dev = protocol_prod_pull.php (registros nuevos / cambiados, una transacción, respaldo; no toca migrations ni kt_logs). Se usa con "pa llevar" o pidiendo "sincroniza producción"; ofrecí crearle su propio comando. Requiere .env.production-db con la contraseña actual en cada PC.
