#772 Completed How to set up KcolTech's PayPal account in the PayPal module (paypal.me is not enough: REST app keys)
Requested Mon, Oct 19, 2026 · 11:19 AM · at Thundera · Category: question · Company: KcolTech
Request
how to setup paypal account.. for example for kcoltech is paypal.me/JuanLock
Understood as
Step-by-step setup of the PayPal module for KcolTech, whose PayPal is paypal.me/JuanLock.
Solution

paypal.me/JuanLock is only a public "send me money" link. Murano can't use it to confirm a payment. To record payments on invoices automatically, Murano needs API keys (Client ID + Secret) from the same PayPal account.

  1. Make it a Business account. paypal.com > Settings: if it says Personal, use "Upgrade to a Business account" (free; the paypal.me link stays the same).
  2. Get test keys (Sandbox). developer.paypal.com > log in with the same PayPal > Apps & Credentials > Sandbox > Create App (name "Murano KcolTech", type Merchant). Copy the Client ID and the Secret.
  3. In Murano, signed in to KcolTech: Settings > PayPal. Paste the Client ID and Secret, choose Sandbox (test), and pick the Deposit account. Suggestion: create an account named "PayPal" in Accounting, since the money lands in the PayPal balance, not in CHASE. Turn on Accept PayPal payments, press Submit, then Test connection.
  4. Test it. developer.paypal.com > Testing Tools > Sandbox accounts has a test buyer (a Personal account) with an email and password. In Sales, open an unpaid invoice's ⋮ menu > PayPal pay link, open the link and pay with that buyer. The invoice should become Paid and show up under Settings > PayPal > PayPal payments.
  5. Go live. Apps & Credentials > Live > Create App > copy the live Client ID and Secret into Settings > PayPal, choose Live, Submit, then Test connection.
  6. Optional webhook: in the live app, Add Webhook. URL: https://murano.kcoltech.com/pay/paypal/webhook/1. Events: Payment capture completed and Payment capture refunded. Paste the Webhook ID it gives into Settings > PayPal.

The sandbox test works now on this PC (kt-murano.local). Live payments need the PayPal module on production first: the code deploy with its migration, which Wake-up / Pa Llevar can do with your yes.

What changed
No code changes. Explained Business account, developer.paypal.com REST app (sandbox, then live), Settings > PayPal fields, sandbox buyer test, webhook URL for company 1.
